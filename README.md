# Minecraft 1.5.2 Vanilla Server

My clean Minecraft server. It has **no plugins** and **no mods** — pure vanilla experience!

## 🚀 How to start the server

1. **Download** the `Server.zip` archive from this repository.
2. **Extract** all files into a separate folder on your PC.
3. **Run** `start.bat`.
4. **Follow the interactive menu** on your screen to choose the server difficulty and game mode. 
   *(If you just press Enter, it will automatically set difficulty to Easy and game mode to Survival).*
5. **Read the tutorial** on the screen to connect, or use the secret code if you need the video guide!

## 📦 Requirements

* **Java 8 (JRE 1.8)** must be installed on your computer.
* **Minecraft launcher** (BetaCraft is recommended) with version **1.5.2**.
